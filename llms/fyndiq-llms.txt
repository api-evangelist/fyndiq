# Fyndiq

> Fyndiq is Sweden's largest marketplace for bargains, connecting merchants with millions of deal-seeking consumers. The Fyndiq Merchant API lets merchants upload and manage product articles and retrieve, fulfil and cancel orders. It is a REST/JSON API secured with HTTP Basic Authentication, with a self-contained sandbox for integration testing.

## APIs

- [Fyndiq Merchant API (developer portal)](https://developers.fyndiq.com/): Developer documentation home for the Merchant API.
- [Merchant API reference (Postman)](https://merchantapi.fyndiq.com/): Full request/response reference for articles and orders.
- [Merchant Center](https://merchantcenter.fyndiq.se/): Web console for merchants.
